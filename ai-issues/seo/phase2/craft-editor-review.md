## PNG to SVG for Cricut

- Chose `/png-to-svg-for-cricut` because its single-color result and current presets give the cut review a concrete starting point. The neighboring general, vinyl, layered, sticker and Print Then Cut tools serve separate workflows.
- Verified the current Threshold, Remove tiny specks, Curve smoothing, Corner handling, Transparent background and Download Cricut SVG labels. The route’s White Vinyl – Dark Preview preset turns on Invert line art, which forces a dark background rectangle into the export. The user must turn off inversion and turn on transparency before updating the result. Distinguish that rectangle from any backdrop traced out of the source image.
- Replaced repetitive troubleshooting with a preview and import workflow covering holes, islands, rough edges and excessive detail, thin filled traces, background rectangles, overlapping copies, final dimensions, mat review and a final-scale material sample. Linked the canonical PNG to SVG converter, SVG Preview Viewer and layered PNG converter.
- Package D uses the source PNG and traced SVG under `public/examples/output-inspection` from package C. Both previews reserve a 320 × 240 aspect ratio and load below the tool. The figure includes downloads for repeatable contour review.
- Design Space instructions were checked against [Cricut’s image upload guide](https://help.cricut.com/hc/en-us/articles/360009556313-How-to-upload-images-into-Design-Space), [unsupported SVG upload items](https://help.cricut.com/hc/en-us/articles/360009553213-Image-uploads-unsupported-items), [Canvas guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide), [Operation guide](https://help.cricut.com/hc/en-us/articles/26922998476183-Design-Space-Selecting-Operation), [Prepare screen guide](https://help.cricut.com/hc/en-us/articles/26762475430167-Prepare-screen-Design-Space-Guide), and [Print Then Cut guide](https://help.cricut.com/hc/en-us/articles/360009387274-How-to-Print-Then-Cut-in-Design-Space). ## SVG Background Editor

- The prior first-party evidence (`ai-issues/seo/first-party-evidence.md` on `origin/codex/reliability-hardening-2026-11-08`) reported 172 background uploads, 153 previews and 109 downloads during its observation window. These events establish use of the workflow. Source review confirmed why an added color can be hidden by a source rectangle and that Checkerboard lives only in the preview frame.
- The built-in example contains a white 120 × 120 rectangle and a blue circle. The revised walkthrough removes the rectangle, verifies the rendered result and SVG markup, downloads, clears the editor, reopens the downloaded file and adds a new opaque background. Remove and Add both derive output from the current input SVG, which makes reopening the first export important. Manual remove is limited to candidate rectangles. Replace embeds and stretches an SVG underlay to the main drawing area.
- Reviewed the neighboring PNG, JPG, WebP, PDF, resize, cleaner, minifier and favicon/ICO tool sources and route records. PNG and WebP have raster transparency options, JPG uses a solid matte, and the current PDF exporter rasterizes the artwork at the chosen DPI before embedding it on a page. The resize editor owns SVG sizing and scaling. Cleaner and minifier address markup, and favicon/ICO targets icon delivery. Added only links needed to continue the background workflow into PNG, JPG and PDF. [MDN image file types](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Formats/Image_types) and [SVG viewBox](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/viewBox).

## Independent mobile documentation review

The recovery guide reflects signature-based PNG/JPEG/WebP preparation, oversized EXIF WebP handling, browser-only centerline tracing, conditional server fallback, and the retry source checks in the PNG converter. The numerical resize example preserves proportions and reduces the pixel count from 24 million to 6 million. Apple confirms the Preview Export menu and JPEG/PNG choices. The PNG switch is labeled Alpha and the flow ends with Save. For edited ProRAW files, Apple specifically documents JPEG sharing via AirDrop, Mail or Messages. Avoid implying that every Photos destination produces a JPEG. No physical iPhone verification was available.
