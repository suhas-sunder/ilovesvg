# Content release history

No content has been published by this workstream. The authoritative machine ledger is `release-history.json`, initially empty. Populate it only following verified deployment.

Each release entry needs `id`, `week` (New York Monday), `actualPublicationDate`, `finalDeployedCommit`, `rollbackReference`, `productionVerification`, and `metrics` with observation dates and unavailable-data notes. Store detailed evidence under `ai-issues/releases/weekly/`. Do not backfill invented performance numbers or a planned date as an actual publication date.
