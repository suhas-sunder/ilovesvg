# Package D browser acceptance

Independent editorial review checked the guide against source and Cricut's linked upload, Prepare and Print Then Cut documentation. The final text says “Make or Make It” to match the two documented interface labels. The primary reviewer separately rendered all clean/recovered downloads and verified the hole, bridge and island pixels. Physical import/cut claims remain excluded.

The immutable package D production build was compared with the PR #12 foundation at `78dda78`. Chromium and WebKit each passed all seven widths (320, 375, 390, 430, 768, 1024 and 1440 CSS pixels). The route returned 200, kept its H1, title, description, canonical, robots metadata and schema types, and rendered the FAQ answers in its existing microdata. Both lazy-loaded example images rendered with their reserved 320 × 240 dimensions. The [report](browser/report.json) records the measurements and links by filename to the screenshots and downloads in the same directory.

At 390 px each engine uploaded the public cut-mark fixture and used Download Cricut SVG. The Clean Cut export was 789 bytes with one path, three subpaths, no images or rectangles, and transparent samples inside the hole and outside the artwork. The bridge, body and disk were opaque. White Vinyl – Dark Preview produced an 848-byte SVG with a full-canvas dark rectangle. Turning off Invert line art, enabling Transparent background and applying Update preview removed the rectangle. The 789-byte recovery export retained the three subpaths. The downloads were parsed and sampled from their rendered pixels. [Independent output verification](../../../seo/phase2/independent-output-check.json).

The package's Node 20 typecheck, build, test and source checks passed. For the browser review, use the same two local production builds and run `node ai-issues/releases/weekly/phase2-craft/review.mjs craft`. Set `BASE_URL`, `BASELINE_URL` and `PLAYWRIGHT_MODULE` to the local endpoints and Playwright module. Browser requests to external services were blocked. Design Space import, physical cutting, physical mobile hardware and genuine ad fills remain separate verification steps.
